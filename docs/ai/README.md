# AI Docs

This directory contains repo-local AI skills and related helper documentation.

## Skills

- [Write PHPUnit Test](write-phpunit-test/SKILL.md): add or update harness PHPUnit tests for `unit`, `integration`, or `smoke`
- [Classify Lib File For Testing](classify-lib-file-for-testing/SKILL.md): assign one top-level `lib/*.php` file to an initial per-file testing strategy
- [Write Lib File Test](write-lib-file-test/SKILL.md): add or update one matching PHPUnit file for one top-level `lib/*.php` file
- [Use Coverage For Tests](use-coverage-for-tests/SKILL.md): use harness code coverage to target and validate PHPUnit test authoring for `lib/*.php` files
- [Triage Lib Test Failure After Change](triage-lib-test-failure-after-change/SKILL.md): classify a changed-file lib test failure before deciding whether code or test should move
- [Write Crawl Plan](write-crawl-plan/SKILL.md): add or update declarative `crawl_plans` in `config/matrix.json`
- [Write Fixture Pack](write-fixture-pack/SKILL.md): add or update deterministic SQL fixture data for tests and crawl coverage
